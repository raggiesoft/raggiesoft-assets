## 1. Executive Overview & Mission (Original Clean-Room Scripting & Declarative UI Engine)

**`RaggieScript` v1.3.0 (`.rssc`)** is RaggieSoft's MIT-licensed, C# / TypeScript-inspired curly-brace scripting, declarative Wizard UI layout, and micro-application language engineered from scratch as the **single unified scripting engine across all 8 RaggieSoft Studio tools** AND RaggieSoft's consumer applications (**StoreTrainer** via **`StoreScript`** and **Book Reader / Story Crossroads** via **`use crossroads;`**). Every construct—from lexical scoping, gradual static type inference (`RSW701`–`RSW715`), `defer` LIFO cleanup, `?.` optional chaining, built-in `test "..."` suites, and `RSWBC2` linear stack bytecode to Per-Monitor V2 DPI Win32 Wizard pages—is 100% plain-text, Git-diffable, and free of hidden binary form files or unverified string-expansion macros.

## 2. Lexical & Syntactic Grammar (`Style A` C#/TypeScript Curly-Brace)

1. **Comments & Regions**:
   - Single-line `// ...` and multi-line `/* ... */` comments (100-level read-along teaching comments required top-to-bottom in hand-authored `.rssc` files!).
   - `#region Title` ... `#endregion` code-folding markers.
2. **Preprocessor & Modular Includes**:
   - `include "relative/module.rssc";` or `import "relative/module.rssc";` (idempotent canonical-path cycle guard, automatic `#pragma once` semantics, exact per-file diagnostic tracking).
   - `#define KEY "VALUE"`, `#ifdef KEY`, `#ifndef KEY`, `#if KEY == "VAL"`, `#elif KEY != "VAL"`, `#else`, `#endif`, and `#error "Message"` (`RSW703`).
   - Build-time embedded files: `compile.json("manifest.json")` and `compile.text("License.txt")` bake external files directly into `RSWBC2` bytecode constants at compile time!
3. **Literals & Null-Safe Operators (`v1.3`)**:
   - **Standard & Interpolated Strings**: `"Installing ${product.name} (${sys.arch()})..."` (supports `\n`, `\r`, `\t`, `\\`, `\"`, `\$`, and nested `${expr}` with accurate column tracking).
   - **Raw Strings (`r"..."`)**: `r"SOFTWARE\RaggieSoft\Book Reader"` — zero double-backslash escaping for Windows Registry keys, UNC shares, and regexes!
   - **4-Part Semantic Version Literals (`v"..."` & bare `X.Y.Z`)**: `v"10.0.22000.1"` or `1.3.0` — first-class `version` values supporting `<, <=, ==, !=, >=, >` directly!
   - **Null-Safe Optional Chaining (`?.` & `?.[`) + Null-Coalescing (`??`)**: `const port = cfg?.network?.port ?? 8443;`, `const first = items?.[0];`, `const ks = overrides?.keys();`.
   - **Numbers, Booleans, Collections**: 64-bit `int` (`42`, `0x1040`, `500_000`), `float` (`3.14`), `bool` (`true`, `false`), `null`, `array` (`[a, b]`), and `map` (`{ key: val, "strKey": val2 }`).
4. **User-Defined Types (`struct` & `enum`), Functions (`fn`), `defer` Cleanup, Lambdas (`=>`), Pattern Matching (`match`), & `test` Blocks (`v1.3`)**:
   ```csharp
   fn patchConfigWithGuarantee(tempDir: path) : bool {
       fs.mkdir(tempDir);
       // `defer` blocks run in strict LIFO order on normal return, early return, or thrown error!
       defer {
           fs.removeTreeIfExists(tempDir);
       }
       const port = net.findFreePort(8400, 8500);
       return port > 0;
   }

   test "Math clamp and optional chaining preserve safe defaults" {
       const cfg = null;
       assert((cfg?.audio?.scale ?? 1.25) == 1.25, "Expected optional chaining fallback");
       assert(math.clamp(250, 0, 100) == 100, "Expected clamped ceiling");
   }
   ```
5. **Top-Level Lifecycle & Metadata Declarations**:
   - `use <capability>;` (`std`, `installer`, `showcase`, `ui`, `help`, `launcher`, `document`, `localization`, `a11y`, `training`, **`storescript`**, **`crossroads`**)
   - `package "<Title>" { ... }`, `showcase "<Title>" { ... }`, or `app "<Title>" { ... }`
   - `param <name>: <type> = <defaultExpr>;` (supports mutable CLI `KEY=VAL` overrides AND IT policy-locked `KEY:VAL` immutable overrides!)
   - `feature "<Id>" { title: "..."; description: "..."; inCompact: true; required: false; delivery: Delivery.Embedded; }`
   - `payload <Id> { from "glob/path" -> destExpr; feature: "Main"; recursive: true; }`
   - `wizard { step <Id> [when (cond)] { ... } }` (side-effect-free `RSW701`-verified UI phase; auto-skipped in `/s` silent mode)
   - `install { ... }` (atomic `.rsw-rollback.jnl` LIFO undo-journaled installation phase; supports `Uac.Deferred` `--elevated-rssc-worker`)
   - `repair(mode) { ... }` and `uninstall(purgeUserData) { ... }`
   - `on hotspot("BtnId").click { ... }` and `on page("Main").show { ... }` (event-driven Showcase Studio handlers)
   - `test "<Name>" { ... }` (first-class automated unit tests executed by `raggiescript.exe test [--json]`, `RaggieScriptVm::RunTests()`, and `RsscManagedRuntime.RunTests()`)

## 3. Gradual Type-Inferred Static Type System & Diagnostic Codes (`RSW700`–`RSW715`)

| Code | Severity | Compile-Time Invariant Enforced |
| :--- | :---: | :--- |
| **`RSW700`** | Error | Lexical / parser syntax error or missing `include` / `compile.json` file (`1-based` line & column). |
| **`RSW701`** | Error | **Wizard Phase Isolation**: Mutating host call (`fs.write*`, `reg.write*`, `shortcut.create`, `com.registerInproc`, `font.install`, `cert.importTrustedPublisher`, `activesetup.register`, etc.) inside `wizard { ... }`, including transitive calls via user `fn`s or lambdas. |
| **`RSW702`** | Error | **Capability Sandbox**: Forbidden host namespace (`fs`, `reg`, `proc`, `ffi`, `net`, `svc`, `msi`, `env`, `com`, `font`, `cert`, `activesetup`) invoked under a sandboxed Studio or Consumer profile (`use training;`, `use a11y;`, `use localization;`, `use document;`, **`use storescript;`**, **`use crossroads;`**). |
| **`RSW703`** | Error | Explicit `#error "..."` compile-time directive triggered. |
| **`RSW704`** | Error | `RSWBC2` / `RSWBC1` binary bytecode header or `SHA-256` digest verification failure. |
| **`RSW710`** | Error | **Undeclared Identifier**: Variable or function referenced before declaration (with fuzzy *"Did you mean '...'?"* suggestion). |
| **`RSW711`** | Error | **Static Type Mismatch**: Incompatible assignment, return value, binary comparison (`version < bool`), or operator operand types. |
| **`RSW712`** | Error | **Signature / Arity Error**: Unknown stdlib method (`reg.writeStrng` -> *"Did you mean 'reg.writeString'?"*), wrong argument count, or incompatible argument type. |
| **`RSW713`** | Error | **Immutability Violation**: Reassigning a `const` / `enum` binding or passing an immutable `const` variable as `ref constVar`. |
| **`RSW714`** | Error | **Invalid Struct / Enum Member**: Unknown field on a `struct` literal/member access or unknown variant on an `enum`. |
| **`RSW715`** | Error | **Control-Flow / Return Error**: `break` / `continue` outside a loop, or non-`void` typed function missing a `return` path. |

## 4. Declarative In-Window Wizard & Custom Dialog DSL

`wizard { step <Id> [when (cond)] { ... } }` renders **genuine Per-Monitor V2 DPI Win32 controls directly inside a single unified Wizard window** across all 11 RaggieSoft styles (`fluentmica`, `standard`, `aerowizard`, `wizard97`, `wizard95`, `fullscreenblue`, `fullscreenteal`, `autorun16x9`, `oneclick`, `passivetoast`, plus automatic `SPI_GETHIGHCONTRAST` Windows Contrast Theme override): `ui.welcome`, `ui.license`, `ui.readme`, `ui.heading`, `ui.label`, `ui.notice`, `ui.folderPicker`, `ui.filePicker`, `ui.textBox`, `ui.checkbox`, `ui.radioCards`, `ui.comboBox`, `ui.featureTree`, `ui.readySummary`, plus turnkey `RsWelcome`..`RsFinishReboot` helpers and `ui.taskDialog`.

## 5. Linear Stack Bytecode ISA (`RSWBC2` Container)

Compiled `.rssc` programs lower into a compact, deterministic **Linear Stack Bytecode (`RSWBC2`)** container verified by a 32-byte `bcrypt.dll` `SHA-256` digest (`kResIdScriptBytecode = 225`), supporting `PUSH_CONST`, `LOAD_VAR`, `STORE_VAR`, `DECL_VAR`, `MAKE_REF`, `MAKE_ARRAY`, `MAKE_MAP`, `MAKE_STRUCT`, `MAKE_CLOSURE`, `GET_MEMBER`, `SET_MEMBER`, `GET_INDEX`, `SET_INDEX`, `JMP_IF_NOT_NULL`, `CALL`, `CALL_HOST` (incl. `?`-prefixed optional method calls), `TRY_ENTER`, `TRY_EXIT`, `THROW`, `DEFER_PUSH` (`v1.3` LIFO cleanup), `WIZ_STEP_BEGIN`, `WIZ_STEP_END`, and `RET`.

## 6. CLI Tooling (`raggiescript.exe`) & Multi-Target Backends

```powershell
# 1. Static Type, Phase (RSW701), & Capability (RSW702) Verification (Human or JSON for CI/AI):
raggiescript.exe check [--diagnostics=json] <script.rssc> [-DKEY=VAL]

# 2. Built-In Unit Test Runner (Single .rssc File or Whole Directory, Human or JSON):
raggiescript.exe test [--json] <script.rssc | directory> [-DKEY=VAL]

# 3. Compile to SHA-256 RSWBC2 Linear Stack Bytecode & Disassemble Opcodes:
raggiescript.exe compile <script.rssc> <out.rswbc> [-DKEY=VAL]
raggiescript.exe disasm  <script.rssc | out.rswbc | packed.exe>

# 4. Canonical Code Formatter & JSON-RPC 2.0 Language Server (VS Code / Studio IDE):
raggiescript.exe fmt [--check] <script.rssc>
raggiescript.exe lsp

# 5. Execute Directly or Pack Standalone Zero-Dependency Windows Micro-App (.exe):
raggiescript.exe run <script.rssc | out.rswbc> [--silent] [KEY=VAL] [LOCKED_KEY:VAL]
raggiescript.exe pack-exe <script.rssc> <Tool.exe> [--support-dir=./_support] [--uac=deferred]

# 6. Transpile Sandboxed `use training;` or `use crossroads;` Script to Browser-Safe ES2022 Module (Zero eval()!):
raggiescript.exe transpile-es2022 <scenario.rssc> <scenario.mjs>
```
