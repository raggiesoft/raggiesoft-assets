# RaggieSoft Studio — 1:1 Master Keyart & Product Emblem Archive

This directory preserves the clean, uncropped, **zero-text `1:1` ray-traced master paintings** created for the **RaggieSoft Studio** 8-product suite. Each painting serves both as the centerpiece illustration on the 1990s big-box retail covers (`../boxes/box-*.png`) and as a standalone visual emblem suitable for desktop `.ico` / `.icns` icons, splash screens, and product logos.
